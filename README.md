# Босоногая Чайка — интернет-магазин керамики с мезенской росписью

Одностраничный сайт: главный экран со слоганом, «Чем мы занимаемся» с фото мастера, каталог (15 работ, разделы,
сортировка, избранное, карточка товара, корзина, оформление заказа), отзывы с Яндекс Карт, контакты с картой,
публичная оферта, политика конфиденциальности и согласие на обработку данных.
Между блоками — орнамент по присланному образцу «Узор.png» (перерисован вектором, `img/frieze.svg`).
Дизайн — по референсу Behance «Homme | Internet shop» (пилюли-кнопки, тонкие линии, крупный заголовок), шрифты —
Neucha для заголовков и подписей и Inter для текста, палитра — киноварь и сажа мезенской росписи.
Слоган: «Сказки Севера, застывшие в глине», в две строки, флаг влево. Логотип и значок вкладки — чайка,
присланная заказчиком (`img/favicon.svg`, PNG-копии 64 и 180 px для браузеров без SVG).

## Как открыть

Файл `index.html` открывается двойным щелчком (нужен интернет для шрифтов Google Fonts). Для локального сервера:
`python -m http.server 8795 --directory ceramic_shop/site` (конфиг `bosonogaya` в `.claude/launch.json`).
Для публикации на хостинге достаточно загрузить `index.html` и папку `img/`.

## Как править

Исходники в `src/`, собирает их `python build.py` (из папки `src`) → `index.html` и `artifact-source.html`.

| Что менять | Где |
|---|---|
| Товары, цены, описания, варианты рисунка, отзывы | `src/data.js` |
| Тексты и блоки страницы | `src/body.html` |
| Оферта, политика, согласие | `src/legal.txt` (нумерация и ссылки между пунктами считаются при сборке) |
| Данные продавца: ФИО, ИНН, ОГРНИП, телефон, почта, адрес, дата редакции | словарь `SELLER` в `src/build.py` |
| Оформление | `src/style.css` |
| Каталог, корзина, окна, форма заказа | `src/app.js` |
| Картинки из папки `ceramic_shop` заново | `python make_assets.py` |
| Орнамент | `python make_frieze.py` |
| Значок вкладки | `img/favicon.svg` (руками, скрипты его не трогают) и PNG к нему |

Тексты типографируются в браузере (`typo()` в `app.js`): неразрывные пробелы, тире, диапазоны, «ст. 26.1», даты.
Проверочные скрипты: `src/tools/` (`cdp.py` — снимки и шаги в headless Chrome, `qa.py` — переполнение по ширине
320—1920 px, корзина, документы, `qa_nostorage.py` — работа без localStorage и буфера обмена).

## Документы: оферта, политика конфиденциальности, согласие

- В подвале три ссылки, окна открываются и из формы заказа. В форме два отдельных обязательных поля: принять оферту
  и дать согласие на обработку данных. Отдельное поле нужно потому, что с 1 сентября 2025 года согласие оформляют
  отдельно от политики и оферты. Строка «Условия оферты принимаю. Согласие на обработку персональных данных даю.»
  добавляется в конец текста заказа, чтобы у продавца осталась письменная отметка.
- ФИО, ИНН и ОГРНИП сверены по открытому реестру ИП. В реестре имя записано «Эвелина», заказчик писал «Эвилина»,
  публично мастера зовут «Лина Альтерман»: расхождение нужно снять (правится одно значение `FIO` в `build.py`).
- Подставлены условия, которые нужно подтвердить у мастера: ответ на заказ в течение двух рабочих дней; Товар
  придерживается три дня после подтверждения; способы оплаты (перевод, СБП, наличные в мастерской); доставку оплачивает
  покупатель, срок называется в подтверждении; возврат надлежащего качества — 7 дней, деньги — 10 дней, обратная
  пересылка за счёт покупателя; данные по заказам хранятся три года; меры защиты данных (пароль на устройствах, доступ
  только у оператора).
- Политика описывает сайт как он есть: он ничего не отправляет на сервер, заказ покупатель передаёт сам. Если появится
  сервер, форма отправки, аналитика или шрифты перейдут на свой хостинг, текст политики нужно обновить.
- Тексты типовые, составлены по Гражданскому кодексу, Закону о защите прав потребителей, правилам продажи товаров
  (постановление № 2463) и 152-ФЗ. Перед запуском их должен посмотреть юрист: например, нужно ли уведомление
  Роскомнадзора, проверить условия хранения данных на территории РФ, добавить регистрирующий налоговый орган из выписки
  ЕГРИП. В каждую посылку нужно вкладывать листок с порядком и сроками возврата: без него у покупателя не 7 дней,
  а 3 месяца (п. 4 ст. 26.1 Закона о защите прав потребителей).

## Источники и авторство

- Фото главного экрана, фото мастера и карточки каталога — из папки `ceramic_shop` (файлы названы «Изображение ChatGPT»
  и `catalog_cards`); перед запуском на живом сайте лучше заменить их настоящими снимками. Карточка «Студёный улов» —
  `catalog_cards/11-fish.png` (четыре тарелки с рыбами), она заменяет `11.png`, где на одной тарелке был бык.
- Карта: тайлы © участники OpenStreetMap (склеены в `img/map.jpg`, подпись на странице обязательна).
- Отзывы: Яндекс Карты, карточка «Босоногая Чайка». Длинные сокращены до целых предложений, опечатки исправлены.
- Шрифты: Neucha и Inter (Google Fonts, лицензия OFL). Neucha есть только в одном начертании, жирного нет.
- Ярмарка Мастеров (livemaster.ru/linaceramica) при сборке закрыта капчей, цены оттуда взяты только из выдачи поиска.
